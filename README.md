# 모두의 문제집 공개 UI 추출본

이 저장소 후보는 운영 앱 전체가 아닙니다. 실제 앱에서 의존성이 분리된 모달, 상단 제목줄, 분야 아이콘, 카탈로그 검색·카드 변환 함수, 공개 이론 응답의 타입, 기본 디자인 토큰과 공개 화면용 CSS만 원본 바이트 그대로 옮겼습니다. 데모의 카드와 문구는 합성 예시입니다.

서버, 계정, 관리자, 문제은행, 정답은행, 데이터베이스, 운영 문서, 배포 설정과 실제 학습 콘텐츠는 포함하지 않습니다. 이 패키지는 Sites 배포본을 빌드하거나 대체하지 않습니다.

```sh
npm ci
npm run check
npm run dev
```

`npm run verify:export`는 정해진 파일 외의 추가 파일, 심볼릭 링크, 원본 파일의 해시 변경, 허용되지 않은 import와 CSS 외부 참조를 거부합니다. 파일을 더 공개하려면 출처와 의존성 경계를 먼저 검토하고 `scripts/verify-export.mjs`의 허용 목록과 `SOURCE_MANIFEST.json`을 함께 검토해야 합니다. 외부 서비스 데이터 없이 `npm run check`로 타입 검사, 동작 검사, Vite 빌드를 수행합니다.

기존 비공개 앱에는 공개 재사용 허가를 명시한 LICENSE 파일이 없었습니다. 이 추출본은 라이선스 허가를 추가하지 않으며, 의존 패키지의 라이선스는 해당 패키지의 배포 자료를 따릅니다. 출처는 `SOURCE_MANIFEST.json`, 의존 패키지 표시는 `THIRD_PARTY_NOTICES.md`에 기록했습니다.
